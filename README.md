# 🍵 Kedai Teh Kuno & Si Oyen (Praktik React Deploy)

Aplikasi Form Masuk & Pendaftaran Akun interaktif bernuansa lukisan sutra klasik abad pertengahan dengan ditemani **Si Oyen**, secangkir teh Longjing hangat, dan petikan instrumen Guzheng yang menyejukkan jiwa.

🔗 **Live Demo (GitHub Pages):**
👉 [https://nafilhub.github.io/praktik_react_deploy/](https://nafilhub.github.io/praktik_react_deploy/)

---

### ✨ Fitur Unggulan:
- 🐱 **Si Oyen Interaktif**: Beri makan ikan segar (`🐟`), elus bulunya (`🌸`), dan dengarkan dengkuran kasih sayangnya.
- 🍵 **Cangkir Teh Celadon Hangat**: Uap teh dinamis dan teguk ketenangan batin.
- 🎵 **Audio Synthesizer Web Audio API**: Nada petikan pentatonik Guzheng & mangkuk meditasi Tibet.
- 🍃 **Kanvas Alam Dinamis**: Sinar matahari emas, lentera teratai mengapung, kupu-kupu terbang, dan dedaunan willow gugur.
- 📱 **100% Responsif di Mobile**: Dioptimalkan untuk semua ukuran layar smartphone dan tablet tanpa horizontal scroll.
- 🔐 **Indikator Harmoni Kunci Sandi**: Validasi kekuatan password dengan filosofi aksara keseimbangan alam.

---

### 🚀 Cara Menjalankan Proyek Lokal:
```bash
# Pasang dependensi
npm install

# Jalankan server pengembangan
npm run dev

# Bangun versi produksi
npm run build

# Deploy ke GitHub Pages
npm run deploy
```
